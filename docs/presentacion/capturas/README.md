# Capturas para el material de presentación

Tomadas del **sitio en vivo** (`https://acueducto-kidotoy.vaisy.app`), no de local.

- **Escritorio:** viewport 1440×900, página completa.
- **Móvil:** viewport 390×844, página completa.
- Todas a **2×** de densidad: se proyectan sin verse pixeladas.
- Sin barras de desplazamiento, sin indicadores de desarrollo y sin avisos flotantes.
- Las imágenes con carga perezosa se forzaron antes de capturar: no hay tarjetas en blanco.

Datos del demo vigente: 25 colaboradores, 40 beneficiarios, 24 referencias,
**avance 70 %**, 12 entregas. Caso estrella: Diana Salcedo (`52318904`) con Jerónimo
confirmado y Valentina y Andrés pendientes.
